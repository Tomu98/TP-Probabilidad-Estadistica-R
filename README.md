# Trabajo Integrador – Probabilidad y Estadística (R)
Este repositorio contiene el trabajo práctico integrador realizado para la materia Probabilidad y Estadística. Incluye el informe final en PDF y el script en R utilizado para procesar los datos, generar gráficos y resolver cada consigna.


## Estructura
```
/data      → Dataset utilizado
/docs      → Informe PDF
/plots     → Gráficos generados
/src       → Scripts en R
```

## Contenido
El proyecto desarrolla tablas de frecuencia, medidas descriptivas, gráficos, probabilidades (binomial, Poisson, normal) y muestreo aleatorio simple aplicados sobre un conjunto de datos provisto para el TP.

**Tecnologías:** R, librería ggplot2 y herramientas básicas de análisis estadístico.
